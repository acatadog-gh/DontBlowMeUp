# 《别炸我！》卡面 UI · Codex v7

## 设计方向
- 关键词：鎏金工坊 / 巴洛克浮雕 / 织纹彩釉 / 铸钢徽记 / 重机械质感
- 相比 v6：舞台改为浮雕徽章底座，增加锦纹、织纹、暗角和金色角饰；卡框更厚重；管钳重绘为连续的上下颌 + 钢制主体 + 手柄结构。

## 文件
- `png/`：14 张牌面 + 1 张统一牌背，共 15 张 PNG。
- 单张逻辑尺寸：600 × 900；实际渲染：2x，即 1200 × 1800。
- `card-ui-v7-overview.png`：整套预览总览。

## Godot 使用建议
- 卡牌比例固定为 2:3，可直接按高度缩放。
- 若后续要做卡牌边框动效，可保留 PNG 整图，或把 `.face-frame` / `.stage` 分层导出。
- 文案当前已烙印在 PNG 中；如果需要频繁改平衡文案，后续可出“无文字主体 + Godot Label”版本。
