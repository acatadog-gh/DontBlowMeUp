《别炸我！》卡牌样式 v4

金属框 · 烫金饰线 · 绶带类别 · 浮雕牌名 —— 插画沿用 v3，框架全面升级

设计规格（v4 与 v3 的区别）

1. 外框：纯色平边 → 类别色金属渐变框，上棱受光、下棱背光，厚度 14px，圆角 30px。每类颜色由「浅 → 深 → 更深」三档构成，不再是一块平色。

2. 卡面：平涂米白 → 米白渐变 + 斜向织物暗纹 + 四周暗角，加内圈烫金细线（inset 7px）与四角金色包角，正装感来自这四层叠加。

3. 类别横幅：纯色圆条 → 燕尾绶带（clip-path 六边切角），金底描边 + 类别渐变 + 内投影。

4. 牌名：普通黑体 → 衬线重字（宋体 900）+ 浮雕双层阴影，字号加大到 33/600。

5. 插画窗：单线描边 → 金属厚框 + 金色内圈线 + 上下内投影，插画有「嵌进金属框」的凹陷感。

6. 底部：裸文字 → 金色渐隐细线 + 铜牌式 NO. 药丸；收集牌组合徽章（×2/×3/5-1）改为金属药丸压在插画窗右下。

7. 统一金色系：所有类别共用同一套黄铜金（#F0DCA6 / #C9A25C / #8A6430），这是整套牌「成套、正规」的关键——类别色负责区分，金饰负责统一。
