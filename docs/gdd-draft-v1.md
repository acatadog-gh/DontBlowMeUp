## 第 3 章 目标用户与场景

- 用户：会玩桌游/轻策略游戏的成年玩家（16+），朋友小圈子（2–5 人）。
- 典型场景：朋友群里发一个链接，凑齐人开一局；单局 10–15 分钟，连续 2–3 局。
- 单次时长：15 分钟内（含准备 ≤ 1 分钟）。
- 不追求「所有玩家」，明确放弃：无联机意愿的纯单机用户（M1 阶段临时由本地热座代替）。

## 第 4 章 目标平台与形态

主平台 WebGL（核验日期 2026-10-28，技术上限以 Unity 官方文档当前版本为准）：

| 字段     | 要求                                                                      |
| ------ | ----------------------------------------------------------------------- |
| 分辨率与朝向 | 设计分辨率 1280×720，横屏；Canvas 等比缩放（Match = 0.5）                              |
| 安全区    | 无刘海遮挡问题；UI 关键点击热区 ≥ 44px                                                |
| 输入     | 键鼠（主）+ 触屏（兼容）：`Click/Select`（左键/点按）、`Hover`（悬停/长按 0.3s）、`Cancel`（右键/返回） |
| 目标帧率   | ≥ 30 FPS（测试场景：满员 5 人局 + 全部手牌展开 + 出牌特效）                                  |
| 内存预算   | 峰值 ≤ 512 MB（待实测：贴图图集 + 音频流式）                                            |
| 包体预算   | 首包压缩后 ≤ 30 MB（待实测；超限则音频转流式、图集降级）                                        |
| 存档     | WebGL 无本地文件写入权限：玩家昵称等轻量数据用浏览器 localStorage，对局数据只在服务器                    |
| 联网     | 必须联网（联机对战）；断线行为见 MECH-007 边界表                                           |
| 部署     | HTTPS 必须（浏览器要求）；纯兴趣项目不接支付、不做账号系统                                        |
| 商店材料   | 无商店上架；发布形态 = 网页链接 + 简单落地页                                               |

降级方案：帧率连续 3 秒 < 25 FPS → 关闭出牌粒子特效并降一档分辨率；恢复条件：帧率回升 ≥ 30 持续 10 秒。

移植批次：手机竖屏版列为 P2（需重做触屏布局与竖版 UI），当前不做。

| MECH-003 | 跳过卡          | 不抽牌直接结束回合                                             | 安全感               |
| MECH-004 | 攻击卡          | 结束自己回合且下家抽 2 次（攻击可叠加）                                 | 陷害                |
| MECH-005 | 预知卡          | 秘密查看牌堆顶 3 张                                           | 信息优势              |
| MECH-006 | 洗牌卡          | 重洗抽牌堆                                                 | 破坏记牌              |
| MECH-007 | 偷牌卡          | 随机抽走目标玩家 1 张手牌（面朝下）                                   | 交互与运气             |
| MECH-008 | 透支【已确认：累进赌命型；v0.5 改为功能牌，2026-10-28】 | **透支是一张功能牌**（牌池 4 张，见 8.2），摸到并打出后进入「透支·连抽中」：① 抽到非爆弹 → 该牌面朝上置于本人面前的「透支区」（全场可见）；② 喊停 → 透支区全部入手，回合继续（可继续出功能牌或正常抽牌结束回合）；③ 抽到爆弹 → 透支立即终止，透支区全部**弃掉**，爆弹本身按 MECH-002 结算（有拆除则救回、无拆除则出局）；④ 救回后回合立即结束；⑤ 透支不设次数上限（炸率递增自带平衡，见 8.3）；⑥ 每回合限打出 1 张透支牌。打出的透支牌本身进弃牌堆，**可被偷走、可被弃牌重洗抽回** | 胆量博弈：连抽越多收益越大，炸掉的风险也越高；且多一层「要不要把透支牌留到关键时刻」的资源决策 |
| MECH-009 | 回合与淘汰状态机     | 见第 6.1 节；v0.6 轮转修订：出 1 张功能牌或抽 1 张牌后回合立即结束（例外：攻击叠层抽满 N 次、透支连抽中） | 流程可预期             |
| MECH-010 | 联机同步         | 服务器权威：所有随机与判定在服务端执行，客户端只表现                            | 公平、防作弊            |
| MECH-012 | 休想卡【v0.6 新增】 | 他人打出功能牌时打出，令其失效（两牌均进弃牌堆）；唯一可在非自己回合打出的牌；不可反制拆除与休想本身；**v0.9.1 匿名响应 / v0.9.3 修订**：出牌后一律进入 **3 秒**倒计时窗口（原 8 秒），不点名不暴露持牌者，持牌者自行打出，无人反制效果生效；**出牌者本人不可反制自己打出的牌**，超时后窗口关闭不能再打休想 | 反制博弈：功能牌不再是稳赚   |
| MECH-013 | 拆弹工具类【v0.9 类别化】 | 5 种等量收集标记（老虎钳/尖嘴钳/管钳/断线钳/液压钳，各 4 张）；**单张可直接打出**——无效果、弃置并结束回合（v0.9.2）；**对子=同种×2**，指定一人**随机盲偷 1 张**（不亮手牌，保密，v0.8 修订）；**三条=同种×3**，念牌名向目标索要（有则必须给）；**五张=五种各×1**，从弃牌堆任选 1 张入手；组合牌均进弃牌堆，可被休想反制 | 攒牌博弈：短期的废牌变长期资源 |

### 6.1 回合状态机（穷举）

| 当前状态      | 触发事件        | 条件        | 目标状态      | 副作用              |
| --------- | ----------- | --------- | --------- | ---------------- |
| 等待开始      | 满足开局人数（≥2）  | 房主点开始     | 发牌        | 服务器洗牌、每人发 5 张    |
| 发牌        | 发牌完成        | 无条件       | 玩家回合      | 确定起始玩家（房主起顺时针）   |
| 玩家回合·出牌阶段 | 出功能牌        | 牌在手且为当前玩家 | 响应窗口      | 功能牌进弃牌堆，进入响应询问    |
| 响应窗口      | 打出休想卡      | 被询问者有休想牌  | 回合结束      | 功能牌失效，两牌进弃牌堆       |
| 响应窗口      | 放弃响应        | 无条件       | 响应窗口/结算   | 询问下一位；全员放弃则结算效果 |
| 效果结算      | 结算完成        | 无条件       | 回合结束      | 工具五张转入选牌阶段；对子/三条直接结算（v0.8）     |
| 玩家回合·出牌阶段 | 打出透支牌      | 手中有透支牌且本回合未透支过 | 透支·连抽中    | 透支牌进弃牌堆；建立本人「透支区」（面朝上公开） |
| 透支·连抽中     | 点抽牌         | 无条件       | 透支·结算     | 抽牌堆顶 1 张进入结算     |
| 透支·结算      | 抽到功能/拆除牌    | 无条件       | 透支·连抽中    | 牌面朝上入透支区；可继续抽或喊停 |
| 透支·连抽中     | 喊停          | 透支区非空     | 玩家回合·出牌阶段 | 透支区全部入手          |
| 透支·结算      | 抽到爆弹        | 无条件       | 透支·爆弹结算   | 透支终止，透支区全部弃掉     |
| 透支·爆弹结算    | 手中有拆除卡      | 无条件       | 回合结束      | 弃拆除，爆弹暗置回牌堆      |
| 透支·爆弹结算    | 手中无拆除卡      | 无条件       | 淘汰        | 玩家出局，爆弹弃置并公开     |
| 玩家回合·出牌阶段 | 点抽牌         | 无条件       | 抽牌结算      | 抽牌堆顶 1 张进入结算     |
| 玩家回合·出牌阶段 | 倒计时归零       | 无条件       | 抽牌结算      | 强制抽牌             |
| 抽牌结算      | 抽到功能/拆除牌    | 无条件       | 回合结束      | 牌入手牌             |
| 抽牌结算      | 抽到爆弹        | 手中有拆除卡    | 回合结束      | 弃拆除，爆弹暗置回牌堆      |
| 抽牌结算      | 抽到爆弹        | 手中无拆除卡    | 淘汰        | 玩家出局，爆弹弃置并公开     |
| 回合结束      | 仍有 ≥2 名存活玩家 | 无条件       | 下一玩家回合    | 攻击叠层处理（下家多抽 N 次） |
| 回合结束      | 存活玩家 = 1    | 无条件       | 结算        | 宣布胜者             |

胜利条件（显式化，2026-10-28 用户确认）：**当所有爆弹都已引爆（未被拆除救回）且只剩 1 名存活玩家时，该玩家为唯一赢家。** 等价性说明：爆弹数 = 玩家数 − 1，每颗爆弹必然淘汰恰好 1 人（被拆除的爆弹会回到牌堆、不算引爆），因此「炸弹全没了」的时刻必然只剩 1 人，两句话描述同一状态。
| 结算        | 玩家点再来一局     | 房主确认      | 发牌        | 牌堆重建             |

未定义转移一律显式忽略并记服务器日志。攻击卡使「下家抽 2 次」时，状态机将「抽牌结算→回合结束」替换为「抽牌结算→抽牌结算」，穷举并入上表第 7–9 行的循环执行。

## 第 8 章 数值与成长框架（可复算）

### 8.1 牌组构成公式

```
bombs = P − 1                     // P = 玩家数, 取值 2–5
defuse_in_pile = P − 1
defuse_in_hand = 1（每人开局固定）
func_cards = 48（固定，见 8.2 明细，v0.9）
开局手牌 = 每人 4 张功能牌 + 1 张拆除（共 5P 张）
draw_pile_size R = 48 + 2(P−1) − 4P = 46 − 2P        // v0.9：功能牌 49 → 48
```

| P | 爆弹 | 牌堆中拆除 | 手中拆除 | 功能牌 | 牌堆张数 R |
| - | -- | ----- | ---- | --- | ------ |
| 2 | 1  | 1     | 2    | 48  | 42     |
| 3 | 2  | 2     | 3    | 48  | 40     |
| 4 | 3  | 3     | 4    | 48  | 38     |
| 5 | 4  | 4     | 5    | 48  | 36     |

（v0.9 重算核对：P=2 → 48+2−8=42 ✓，P=5 → 48+8−20=36 ✓。）

### 8.2 功能牌明细（共 48 张，v0.9 全等量）

| 卡牌    | 张数 | 编号       |
| ----- | -- | -------- |
| 跳过    | 4  | MECH-003 |
| 攻击    | 4  | MECH-004 |
| 预知    | 4  | MECH-005 |
| 洗牌    | 4  | MECH-006 |
| 偷牌    | 4  | MECH-007 |
| 透支    | 4  | MECH-008 |
| 拆弹工具类 | 20（5 种各 4） | MECH-013 |
| 休想    | 4  | MECH-012 |

48 = 4×7 + 20，核对一致；**12 种功能牌全等量各 4 张**（v0.9 结构）。

**拆弹工具类明细（MECH-013，v0.9）**——对齐爆炸猫「五只猫」设计：5 种在规则上完全等价的收集标记（老虎钳/尖嘴钳/管钳/断线钳/液压钳），**每种 4 张、共 20 张**，单张无效果，效果由组合决定（同种×2 对子 / 同种×3 三条 / 五种各×1 五张）。

张数设计依据（v0.9 推翻 v0.8 的每种 3 张）：3 张时三条=集齐该种全部，几乎不可能达成、对子也缺乏容错（v0.8 实测前评估，NUM-006 红线风险高）；4 张让对子有冗余、三条需 3/4 仍有稀缺感、五张组合可达。配套把七种常规功能牌统一压到各 4 张，功能牌总数 49→48，4 人局开局爆率 7.9% 与 v0.8 的 7.7% 持平——组合玩法升温而节奏不变。**待实测红线（NUM-006）**：每局至少 1 次工具组合，0 次则加"弃 1 张工具换抽牌"获取渠道而非继续加张数。

### 8.3 关键概率公式（附极值验算）

```
p_bomb(首次抽牌) = bombs / R          // R = 46 − 2P（v0.9）
透支连抽 k 张的累计炸率 = 1 − Π(i=0..k−1) (R − bombs − i) / (R − i)
```

极值验算（首次抽牌）：

- 最小值（P=2）：1/43 ≈ 2.3%——双人局开场几乎不炸 ✓
- 最大值（P=5）：4/37 ≈ 10.8%——满员局开局约九分之一炸率；牌池进一步变大后前期更安全、后期随 R 缩小压迫感后移（符合「先攒牌型后搏命」的节奏）
- 结果随 P 单调上升、随 R 减小单调上升，无负值/越界 ✓

透支连抽累计炸率（以 P=4 开局，R=39、爆弹 3 代入）：

| 连抽张数 k | 累计炸率 | 期望收益（停手得牌数） |
| ------ | ---- | ------------ |
| 1 | 7.7%  | 1 张 |
| 2 | 15.0% | 2 张 |
| 3 | 21.9% | 3 张 |
| 4 | 28.4% | 4 张 |

（示例复算 k=2：1 − (36/39)×(35/38) = 1 − 1260/1482 ≈ 15.0%。）

设计含义（v0.7 更新）：功能牌池变大 + 轮转加快后，单回合决策收敛为「出这张还是抽一张」，透支成为稀缺资源（4 张）；休想卡让所有功能牌效果都可能被反制，出牌前要猜测对手手里的休想；拆弹工具类给攒牌玩家长期目标（同种凑对子/三条、五种凑全家福），稀有工具 2 张/种卡住五张组合的出现频率。**数值待实测校准**，红线：透支牌打出率 ≥ 40%（摸到过的回合中）、休想反制率 15–40% 之间（低于 15% 说明功能牌太强，高于 40% 说明功能牌太弱）。

### 8.4 单局时长验算

估算：4 人局，每人回合 20–30 秒（含 2–3 次决策），淘汰节奏约每 2.5 轮 1 人 → 全局 6–9 轮 ≈ 4 人 × 7 轮 × 25s ≈ **12 分钟**，落在 10–15 分钟目标区间。标注：**待实测**（M1 结束时用 3 场录像实测校准，偏差 > ±30% 则调牌堆构成）。
