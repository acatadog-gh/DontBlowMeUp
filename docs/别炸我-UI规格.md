## 一、风格锚点 v9（逐字复用，一张不改）

> 参照：用户提供的独立桌游角色卡网格截图（巫师动物角色：扁平几何、棱面切角阴影、点状表情、纯色底）。
> 版式沿用 v2.5（深框白板 + 居中标题 + 220×181 插画窗 + 居中描述），仅插画风格切换。

```
桌游卡面插画，扁平几何风格（独立桌游角色卡气质）：
色块拼接造型，棱面切角阴影（亮面与暗面是边界清晰的几何多边形，非柔和过渡），
无描边或极窄同色系深色块收边，无渐变无纹理无噪点，
头大身小的简洁角色，表情极简（小黑圆点眼 + 短弧线嘴），姿态端正可微歪头，
道具小而精（安全帽、扳手等职业道具），
背景为单色平面色块铺满画布，无任何装饰。
限定色板：芥末黄、藏青、钴蓝、砖橙、赭石、暖白。
气质：独立桌游的极简可爱，安静、利落、有设计感，像一套收藏角色卡中的一张。
禁忌：写实、赛璐璐高光、渐变天空、速度线、噪点纹理、复杂背景、
夸张大表情、露齿、文字、水印。
```

### 角色规则（D-12，取代 D-11 的动作场面）

- 每张牌 = 一个**职业装扮的几何小角色**，安静站姿 + 一件小道具（爆弹 = 安全帽 + 扳手的拆弹工）
- 主体占画面 60–70%，居中，纯色背景即类别底色区
- 表情一律极简（点眼 + 弧线），性格靠帽子/道具/体色区分，不靠表情幅度
- 后续牌脚本：拆除 = 拿大剪刀的钳子角色、五把钳 = 五只不同体色持不同钳的队列……

### 技术约束（每张原样追加）

```
横向构图，主体居中，四周留白均匀，主体占画面 60%–70%；
背景单色平整铺满整个画布；
画面内不出现任何文字、字母、数字、水印、签名、边框、卡片轮廓；
不添加外发光、外阴影。
```

### 后处理管线（v9 起，单色背景版）

- 水印区直接用**附近背景中位色**覆盖（单色底无纹理，比镜像补丁更干净）
- 按窗口比例 1.213 居中直裁（全高）

卡面不含文字/数字/角标的理由不变：组合提示是实时状态、文案随平衡调整。**《卡牌设计规范》的印刷向字段（费用/攻击防御等）本游戏没有对应机制，模板字段表按 brief 的 14 种牌裁剪。**

**v2.5 修正依据**：

- **插画窗 220×181**：生成源为 912×752（1.213），v2.4 的 216×204（1.059）把图横向压扁 14%——"比例不太对"的根因；新窗口与源比例一致，零变形

- **描述居中**：徽章移除后文字区整宽（252），居中比左对齐更平衡；字号 13 px / 行高 26，底部块呼吸感更好

|---|---|---|

| 反制（休想） | `#8A5A9E` 深梅紫 | |
| 工具 ×5 | `#D99A3D` 芥末杏 | brief 待确认项 1 的终版提案 |

六色全部落在插画的限定色板内（奶油白/深可可/砖红/杏黄/青绿/雾蓝），版式与插画共用一套色板——这是"出版感"的关键：**卡面上出现的每一个颜色都必须在这六个色里**（引擎高亮 `#E8B04B` 只用于选中描边，不进卡面）。

## 九、命名与资源清单

```
ui_card_<类型>_<名称>_<状态>@v<版本>.png
```

类型 `base` / `art` / `back` / `badge`；全小写 ASCII；版本递增不覆盖。内部标识符避开《爆炸猫》卡名：`deny`（休想）/ `disarm`（拆除）/ `foresee`（预知）/ `bomb`（爆弹）。

## 十三、Godot 4.7 落地（不变，数值更新）

- 拉伸：Display → Stretch → Mode `canvas_items` / Aspect `expand`
- 卡牌 Control `pivot_offset` = 底边中点，`scale = 0.75`，不重出图
- 底板/插画 `TextureRect`；高亮框 `NinePatchRect` `patch_margin_left/top/right/bottom = 32`（具名四值，Godot 顺序左上右下）
- 文字 `Label` + MSDF + outline 4 `#4A3B32`——牌名不随位图缩放糊掉的关键
- 图集用 `AtlasTexture` 手动建；九宫格节点判定现在做完，进引擎改不了
